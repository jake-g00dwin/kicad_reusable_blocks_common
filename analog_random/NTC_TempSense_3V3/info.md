# NTC 3.3V Temperture Sensor Block

## Description

This design block uses a NTC resistor as part of a voltage divider network 
in order to sense temperature.

The voltage drop accross the NTC is amplified using a jellybean op-amp to
amplify the signal for use with a 3.3V ADC in order to get a better reading.

## Ratings

All components selected should be rated for 3.3V at minimum.

## Design Recommendations

For Handsoldering through hole components should be selected or 0805(metric)
sized components.
